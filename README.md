# Vehicle Rental Management System

A terminal-based Vehicle Rental Management System built using Core Java and JDBC.

The system will allow users to manage vehicles, customers, and vehicle rentals through a menu-driven console application.

## Commit 2

This commit introduces the core domain model and OOP structure:
- Abstract `Vehicle` base class
- `Car` and `Motorcycle` subclasses demonstrating inheritance and polymorphism
- `Customer` model with encapsulated fields
- `Rental` model with rental-day and total-cost calculations
- Updated `Main` class with a small model demonstration

The database and CRUD layer will be added in later commits.
